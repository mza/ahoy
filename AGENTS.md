# Notes for coding agents

ahoy is a TypeScript TUI (run directly by Node 23.6+, compiled to standalone binaries by Bun) that plays ascii.rest pieces in a terminal, plus a native macOS screensaver in `macos/` that plays the same pieces through JavaScriptCore.

- **Making or changing pieces:** read [docs/MAKING-PIECES.md](docs/MAKING-PIECES.md) first. It covers the look the user wants, the piece contract, how to render and review pieces, the techniques and tools in `tools/art/`, and what has failed before.
- **Which pieces ahoy plays:** [`src/own.ts`](src/own.ts), for both the app and the screensaver. Only season one (the painted scenes, pack `season-one`), Resilient Hearts (the three shirt designs, pack `resilient-hearts`) and the AWS logo are listed by default; the other packs are prototypes, listed with `--prototypes` or `p` in the picker, and left out of the macOS screensaver. Most commands that should cover every piece need `--prototypes`.
- **Verify before you finish:** `npm run typecheck`, `node tools/art/check.mjs <slug>` for any piece you touched, `python3 tools/smoke.py` (every piece, the picker and the screensaver in pretend terminals; about half a minute), `npm run build`, then check that `./dist/ahoy all --prototypes | grep '\\u[0-9a-f]\{4\}'` prints nothing (Bun escapes non-ASCII in `String.raw`). For the screensaver: `npm run saver`.
- **Scenes in a terminal and a browser:** a terminal cannot draw a scene's round dots on a square grid; `src/stage.ts` has five ways of coming close (`d` cycles them) and lays them out by the cell shape the terminal reports. `ahoy saver` plays in a browser by default (`src/web.ts`), which is the real thing: a page with a canvas, fed frames over server-sent events, each piece for 90 seconds and fading into the next. `--terminal` keeps it in the terminal; tests that drive the terminal screensaver need that flag, or they open a browser. The user compared every terminal attempt with the website (deadmenshipnocode.com) and ascii.rest and found it wanting until this.
- **Publishing:** the repo is [mza/ahoy](https://github.com/mza/ahoy) on GitHub; CI runs on every push to `main`. To release, bump `version` in `package.json` and push a matching `vX.Y.Z` tag (see the README's Release section).
